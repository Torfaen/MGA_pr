# MGA

基于MAAfw的自动化项目，用于完成SD高达永恒的任务自动化。

## 目前已实现功能

1. 每日任务自动化
2. 困难扫荡自动化
3. 材料本自动化
4. 自动困难关卡战斗(指定次数刷取)
5. GP获取自动化

## 后续预计追加功能(无序)

1. 角色委托自动化

## 使用须知

1. 本项目开发人员有限,功能实现进度缓慢
2. 使用手册还在编写中

Windows 便携包建议通过 `启动MGA.cmd` 启动。它会查找正在运行的 MuMu 或系统中的 ADB，只对本次 MGA 进程设置 ADB 路径，不修改系统环境变量。直接运行 `MGA.exe` 时，如果 ADB 不在用户的 `PATH` 中，MFAAvalonia 可能无法自动发现模拟器。

如果希望以后直接双击 `MGA.exe`，可先运行一次 `adb路径配置.cmd`。它会把检测到的 ADB 目录加入当前 Windows 用户的 `PATH`，然后重新打开 MGA。其他电脑需要分别运行一次；无需复制开发机上的绝对路径。
