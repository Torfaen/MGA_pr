# Maa 图像匹配实验室

Windows 本地 HTML 工具，直接调用仓库自带的 MaaFramework Python 绑定和原生识别器。

## 启动

双击仓库根目录的 `启动图像匹配工具.cmd`，或本目录的 `启动匹配实验室.cmd`；也可以运行 `launch.ps1`。启动脚本会自动选择空闲的本机端口并在默认浏览器打开工具。服务在启动它的 PowerShell 窗口前台运行，截图错误和异常堆栈会显示在该窗口；Maa 原生日志保存在 `%TEMP%\MGA-match-lab\logs`。页面中的“关闭服务”会停止本地服务并返回 PowerShell 提示符。

## 用法

1. 在左侧选择模拟器配置并截取当前画面，或在待搜索画面框中选择、拖入、粘贴图片。
2. 选择 Pipeline 文件与识别节点。工具会读取节点的识别类型、ROI 和参数；也可以不选节点，手动调参。
3. 对 `TemplateMatch` / `FeatureMatch` 选择 Pipeline 模板，或在模板图框中粘贴/拖入另一张图。`ColorMatch` 使用颜色上下限，不需要模板图。
4. 运行当前节点的识别，查看 Maa 返回的命中状态、相似度/匹配点或像素数量、坐标框与候选结果。

ROI 坐标使用 `[x, y, w, h]`。也可以点“框选”后在待搜索画面上拖动。模拟器截图使用 Maa ADB 控制器的截图和缩放配置；从剪贴板或文件载入的图片按原始像素识别。

`TemplateMatch` 显示 Maa 的 0–1 匹配得分；`FeatureMatch` 显示特征匹配点数；`ColorMatch` 显示颜色命中像素数。这三种算法的度量含义不同。

本地服务只绑定 `127.0.0.1`，截图与图片识别请求都在本机处理。自定义模板缓存和 Maa 日志放在系统临时目录 `MGA-match-lab`，不会写入项目资源目录。
