# Maa ROI 坐标工具（独立版）

独立页面和启动入口，不需要先打开图像匹配实验室。双击 `启动ROI坐标工具.cmd`，或在 PowerShell 运行 `launch.ps1`。

工具支持从剪贴板粘贴、拖入或选择图片，也可以从项目中的模拟器设备直接截图；支持多 ROI、鼠标左键拖框、右键 / Ctrl+Z 撤销、Esc 清空、输入角点或 XYWH 坐标显示框、10%–300% 缩放和一键复制两种坐标格式。

模拟器截图使用项目的嵌入式 Python 与 Maa ADB 绑定。服务仅绑定本机地址，独立日志位于 `%TEMP%\MGA-roi-lab\logs`，运行日志会显示在启动器打开的 PowerShell 窗口。
